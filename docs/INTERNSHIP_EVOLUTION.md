# 🔄 Project Evolution — NIT Kurukshetra Research to Full-Stack SaaS

## 1. Phase 1: Research Internship Prototype (NIT Kurukshetra)
- **Framework**: Python + Flask.
- **Scope**: Experimental research focusing on multimodal feature extraction algorithms:
  - Extracting optical motion vectors using OpenCV.
  - Analyzing audio frequency dynamics and RMS power using Librosa.
  - Evaluating baseline machine learning regression models on feature vectors.
- **Outcome**: Validated that combination of visual pacing metrics and acoustic energy features could provide meaningful inputs for automated video quality assessment.

---

## 2. Phase 2: Independent Full-Stack Engineering Expansion
- **Backend Redesign**: Migrated from Flask to **FastAPI** with asynchronous request handling and OpenAPI validation.
- **Frontend Architecture**: Built a **Next.js 14** application with Tailwind CSS, Chart.js diagnostic widgets, and client-side workspace isolation in `localStorage`.
- **Platform Blueprint Engine**: Developed heuristic optimization matrices tailored for YouTube Shorts, TikTok, and Instagram Reels based on industry-accepted format specifications.
